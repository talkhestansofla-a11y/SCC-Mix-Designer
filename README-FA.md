# طرح اختلاط بتن خودتراکم — نسخه بازطراحی اولیه

## ساختار
- `www/index.html` پوسته برنامه
- `www/style.css` ظاهر و چیدمان
- `www/app.js` منطق صفحات و محاسبات
- `capacitor.config.json` تنظیمات Capacitor
- `package.json` وابستگی‌ها
- `.github/workflows/android.yml` ساخت APK و اعمال آیکون‌ها

## فایل‌های آیکون
سه فایل PNG موجود در مخزن باید بدون تغییر نام در پوشه ریشه `assets` باقی بمانند:
- `assets/icon-only.png`
- `assets/icon-background.png`
- `assets/icon-foreground.png`

گردش‌کار GitHub Actions پس از افزودن پلتفرم Android، دستور تولید آیکون‌ها را اجرا می‌کند.

## نکته مهندسی
این نسخه، بازطراحی اولیه صفحات و پیاده‌سازی بانک جداول ۱-۶ تا ۶-۶ است. شکل ۷-۶ و جداول مربوط به ترکیب خمیر هنوز به داده عددی کالیبره‌شده تبدیل نشده‌اند؛ بنابراین ورودی نسبت آب به سیمان دستی و با هشدار مشخص شده و گام‌های ترکیب خمیر و مقدار نهایی سنگدانه هنوز فعال محاسباتی نیستند. خروجی برای طرح اجرایی باید با مخلوط آزمایشی و آزمایش‌های لازم تأیید شود.
